## 🚀 Getting Started

This portfolio is a **pure HTML/CSS/JS** website — no build step required.

### Open Locally
1. Download or clone this folder
2. Double-click `index.html` to open in your browser
3. Done! ✅

### Host Online (Free Options)
- **GitHub Pages**: Push to a repo → Settings → Pages → Deploy from main branch
- **Netlify**: Drag and drop the folder at [netlify.com/drop](https://app.netlify.com/drop)
- **Vercel**: Connect your GitHub repo at [vercel.com](https://vercel.com)

## ✏️ How to Edit Content

### Update Personal Info, Social Links, Resume Path
Open `data.js` → Edit the `CONFIG` object at the top:
```js
const CONFIG = {
  name: "Bragadish Mohankumar",
  email: "your@email.com",          // ← Change this
  resumePath: "./resume.pdf",        // ← Replace resume file
  social: {
    github: "https://github.com/...",
    linkedin: "https://linkedin.com/...",
  }
};
```

### Add/Edit Projects
In `data.js`, find the `PROJECTS` array and edit or add project objects.

### Add/Edit Skills
In `data.js`, find the `SKILLS` object and update each category.

### Update Education
Edit the `EDUCATION` array in `data.js`.

### Add Achievements
Edit the `ACHIEVEMENTS` array in `data.js`.

### Update Certificates
Edit the `CERTIFICATES` array in `data.js` — add credential links when available.

---

## 📄 Add Your Resume

1. Place your resume PDF file in this folder
2. Name it `resume.pdf` (or update `CONFIG.resumePath` in `data.js`)
3. The Download Resume button will now work automatically
